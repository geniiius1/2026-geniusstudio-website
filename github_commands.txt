# 1. Update Website (Standard Workflow)
# Run these 3 commands every time you make changes locally:

git add .
git commit -m "Update website"
git push

--------------------------------------------------

# 2. If Push Is Rejected (e.g., changes made on GitHub or CNAME added)
# If git push gives an error saying "[rejected] (fetch first)", run:

git pull --rebase origin main
git push

--------------------------------------------------

# 3. Check What Changed
# See which files you modified, added, or deleted before committing:

git status

--------------------------------------------------

# 4. Initial Setup (First time only on a brand-new project/folder)

git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/geniiius1/2026-geniusstudio-website.git
git push -u origin main
