# Branding Assets

Place your Genius Studio branding assets in these folders.

## 📁 `logo/`
Your main website logo. The site references:
- **`logo.svg`** — Primary logo (recommended: SVG for crisp rendering at any size)
- You can also use `logo.png` — just update the `<img src="branding/logo/...">` in all HTML files

The logo appears in:
- Navigation bar (all pages)
- Footer (all pages)

**Recommended size:** 32–40px height for the navbar version.

## 📁 `favicon/`
Your browser tab/bookmark icons. The site references:
- **`favicon.ico`** — Classic favicon (16x16, 32x32 multi-size .ico)
- **`favicon.svg`** — Modern SVG favicon (preferred by modern browsers)
- **`apple-touch-icon.png`** — Apple device home screen icon (180x180px recommended)

### Quick Setup:
1. Create your favicon at https://favicon.io/ or https://realfavicongenerator.net/
2. Download the generated files
3. Place them in this `favicon/` folder
4. That's it — all HTML pages already reference these paths!
